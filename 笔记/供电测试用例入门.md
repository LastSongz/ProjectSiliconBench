# 供电测试用例入门

沿用软件测试中熟悉的结构：给定条件、施加输入、观察输出、对照预期。硬件用例还要写清楚测点、参考地、仪器和采集设置，便于复测。

| 用例字段 | 核心电源轨负载瞬态示例 |
| --- | --- |
| 被测对象 | CPU 核心电源轨，记录板卡版本和测点 |
| 初始条件与触发 | 记录初始运行状态，再触发一次明确的负载变化 |
| 观察方法 | 用示波器采集测点电压，记录探头连接和触发条件 |
| 观察量 | 最低电压、下跌幅度、恢复时间和对应波形 |
| 判定 | 按适用规格中的限值和测量定义判定。规格待确认时，先记录结果并将判定标为待确认 |

先用这个示例做一次纸面练习。拿到真实测试案例后，用 [[实验记录模板]] 记录条件、波形和结论，再把条目链接到 [[实验记录]]。
