# 硬件测试待学习清单

从手机 SoC 供电入手。按下面的自测任务检查进度，岗位明确后再调整后续专题。

## 1. 听懂讨论并定位术语

- [ ] 看懂电压、电流、功率、负载和参考地。[[电路与测量入门]]
- [ ] 画出电池、PMIC、电源轨和 SoC 供电域的关系，认出 Buck、LDO 和电源轨。
- [ ] 区分稳态、负载瞬态、上电时序、功耗和保护测试。[[芯片供电测试地图]]

**自测**：听到「CPU 一加负载，核心电压掉了一下」，能指出这是核心电源轨的负载瞬态，并追问测点、下跌幅度和持续时间。

## 2. 看懂规格和测量结果

- [ ] 从一份电源器件数据手册里找到测试条件、典型值和最小／最大限值。
- [ ] 知道何时用万用表读稳定电压，何时用示波器看波形。
- [ ] 从示例波形上读出稳态电压、最低电压和恢复时间，说明参考地、探头连接和采集设置为什么要记录。

**自测**：给一张波形和一条规格，能解释读数与规格是否可直接比较，以及还缺什么条件才能判定。

## 3. 写用例并在指导下复测

- [ ] 给一路电源写一条稳态用例和一条负载瞬态用例，列出条件、测点、操作和判定依据。[[供电测试用例入门]]
- [ ] 用 [[实验记录模板]] 保存仪器设置、原始波形和结果。
- [ ] 遇到异常时，逐项复核测量设置和负载条件，并记录是否能重现。

**自测**：把记录交给同事，对方能按记录复测。有可用台架时，在指导下执行一次。手头只有示例数据时，可以先完成用例和判定练习。

## 4. 用开发经验提高重复测试效率

- [ ] 用熟悉的语言读取仪器导出的 CSV，校验单位、缺失值和列名。
- [ ] 按规格输出通过、失败或待确认，并保留原始数据。
- [ ] 有设备可用后，再学习仪器远程控制和批量采集。

**自测**：给脚本一批示例数据，能重复生成相同的结果，并从失败项追溯到对应原始记录。
